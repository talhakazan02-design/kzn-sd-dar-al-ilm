1. Sicherung der aktuellen Website behalten.
2. SUPABASE-SETUP.sql einmal im Supabase SQL Editor ausführen.
3. In Supabase Authentication > URL Configuration die GitHub-Pages-URL als erlaubte Redirect URL hinzufügen.
4. Dateien aus dieser ZIP ins Repo hochladen.
5. Mit zwei Testkonten prüfen: Mitglied stellt Anfrage, Admin genehmigt, Mitglied erhält E-Mail und legt selbst Passwort fest.
Hinweis: Supabase E-Mail-Limits und SMTP-Konfiguration können Versand verhindern. Der Admin sieht oder setzt keine Passwörter.
